# ADR 0001：子任务是独立任务文件

- 状态：接受
- 日期：2026-08-06

## 背景

旧格式把子项放在父任务 frontmatter 的 `steps` 数组中。这样无法为子项单独设置日期、提醒、重复、收藏或备注，父任务文件也会成为并发修改热点。

## 决策

子任务与顶层任务使用同一种任务实体和 Markdown 格式，每个子任务拥有独立 UUID、revision 和文件，并通过 `parentId` 指向直接父任务。目录位置决定项目归属，`parentId` 只表达任务层级。

顶层列表不重复展示子任务；父任务详情按 `parentId` 查询直接子任务。完成父任务不级联完成子任务，完成子任务也不自动完成父任务。

## 后果

子任务可以独立同步、冲突处理、收藏、安排日期和提醒。读取项目时需要建立按 `parentId` 分组的内存索引。旧 `steps` 数据需要在 task@2 迁移中逐项转换为独立 Markdown，迁移成功前保留原字段和恢复副本。
