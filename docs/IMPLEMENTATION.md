## 2026-08-06 项目交互与主题批次

工作目录迁移按产品决定改为“复制、校验、删除旧目录、切换”，不再保留恢复副本。项目配置新增图标、描述、侧边栏颜色、主题和折叠状态；项目可在标题菜单中改名、移动、排序、换主题和归档，右键属性可集中编辑。侧边栏项目树可折叠、双击原位改名；账号入口移至侧边栏底部。子任务作为独立任务出现在中间列表，并由父任务控制展开。视觉采用浅绿雾面、半透明面板和柔和层次，未复制参考产品素材。

## 2026-08-07 主布局回归修复

真实主界面复现发现 CSS Grid 将侧边栏宽度 `278px` 误写进了行定义，导致侧边栏只有约 278px 高、账号入口悬在页面中部并产生整窗滚动。现改为固定 42px 标题栏与 `minmax(0, 1fr)` 内容行；未选任务时详情轨道为 0，选中任务时才扩展为 340px。Electron 冒烟新增运行时尺寸门禁：1280×800 窗口中侧边栏高度必须超过 700px且不越界、主列表宽度超过 900px、body 不得产生额外滚动。

## 2026-08-07 图标、字体与点击热区

移除界面功能控件中的字符图标，改为项目内统一 SVG 图标组件：24×24 viewBox、1.8px 圆角描边，导航、窗口按钮、任务、详情和菜单共用同一视觉规则；默认项目的文件夹 Emoji 也替换为 SVG，用户自行设置的项目图标仍按原值显示。字体改为优先使用 Windows 的 `Segoe UI Variable Text`，中文由 `Microsoft YaHei UI` 回退，标题使用 `Segoe UI Variable Display`。所有按钮、任务卡片、项目行和色板均显示手形光标；项目与任务展开热区分别扩大到 34×36 和 32×32，并提供 hover 与键盘焦点反馈。Electron 冒烟会检查展开热区尺寸及关键控件的计算 cursor。

## 2026-08-07 项目头部、统计与主题设置

项目树每行显示“未完成顶级任务 / 未完成全部任务”，项目头部同步显示带文字的两项统计。项目标题改为从根项目到当前项目的可点击面包屑，日期和描述移到其下方，统计与更多按钮在同一操作基线。设置新增 220–380px 侧栏宽度，新增林间、海岸两套随应用打包的本地 SVG 图片主题，以及自定义强调色、背景色和本地背景图片。项目菜单复用全部内置主题，并在全局自定义主题存在时提供“自定义”入口；选择只更新当前项目的 `.bearai-project.json`。Electron 冒烟验证两级面包屑、统计文案以及从项目菜单选择林间主题后 `theme-forest` 实际生效。

## 2026-08-06 运行时缺陷修复

根因是 sandbox preload 使用 ESM 编译产物，bridge 未注入后渲染层又静默使用内存 mock，造成任务看似成功但重启丢失，分组则无反馈。现改为 sandbox 可执行的 CommonJS preload，增加健康检查并移除全部任务内存回退；bridge 失败会显示错误。Vite 生产资源改为相对路径，`npm start` 加载构建版，只有 `--dev` 才访问开发服务器。真实 Electron 冒烟已验证分组和任务可重新读取且对应 Markdown 文件存在。
