- 项目支持顶级同级及同父子项目排序；目标行中央可把子项目及完整子树跨父移动，上下边缘继续只做同父排序。自身、后代、顶级项目跨父等非法目标不触发 IPC；子项目“移动到”仍作为替代入口，过滤当前父级、自身、后代和归档目标，并采用确认、revision 校验、目录整体 rename 与配置失败回滚。

- 自动测试覆盖领域行为；Electron smoke 通过完整 dragstart/dragover/drop 事件链并回读 Markdown。Windows 原生 SendInput 会进入 Chromium 阻塞 drag loop，未作为稳定 CI 方案；真实人工鼠标验收仍需单列。

## 2026-08-06 运行时缺陷修复

根因是 sandbox preload 使用 ESM 编译产物，bridge 未注入后渲染层又静默使用内存 mock，造成任务看似成功但重启丢失，分组则无反馈。现改为 sandbox 可执行的 CommonJS preload，增加健康检查并移除全部任务内存回退；bridge 失败会显示错误。Vite 生产资源改为相对路径，`npm start` 加载构建版，只有 `--dev` 才访问开发服务器。真实 Electron 冒烟已验证分组和任务可重新读取且对应 Markdown 文件存在。

## 2026-08-07 自动保存、Milkdown 与展开模型修正

preload 对 task、嵌套 attachment、project patch 与 settings patch 统一转换为 JSON 兼容纯 DTO，渲染调用附件操作前再次去除 Vue Proxy，修复 `An object could not be cloned`。任务文本采用 550ms 防抖、单队列串行保存；关闭详情、切换任务/项目和应用关闭按钮会 flush。界面显示未保存、正在保存、已保存、保存失败；失败不再调用 `load()` 覆盖草稿，revision 冲突同时保留本地和磁盘版本供选择。

高级详情宽度固定为窗口的 50%，窄窗口仍采用右侧覆盖层，列表区不产生横向滚动。高级编辑器为 Milkdown/Crepe，正文仍只写 Markdown；固定工具栏暴露标题、粗体、斜体、删除线、列表、引用、代码与撤销/重做，图片进入受管附件并通过安全协议显示。截止时间和提醒使用 Vue Datepicker，并在外层提供今天、明天、下周等快捷选择；保存格式仍为 ISO 8601。项目菜单分成独立“任务展开”和“项目展开”。任务展开在界面上是三个互斥选择：默认不展开、默认展开到固定层级、记住上次展开情况；选择前两项会关闭记忆，选择记忆时保留既有默认策略作为无有效历史状态时的内部回退，但不会同时显示两个勾选。项目字段 `showSubprojects` 仍与任务展开双向不联动。固定深度只有第一至第五层和全部。

- 刷新过程中拒绝重复触发；读取失败沿用可关闭错误条，不用旧内存状态伪装成功。隔离 Electron 冒烟通过仓储创建一个 UI 尚不可见的项目，确认点击刷新后项目树出现该项目。

## 可恢复的作废任务（2026-08-09）

- task@2 以可选字段加入 `voided` 状态、当前作废时间/原因和状态历史，恢复时回到 active 并保留审计历史，不删除 Markdown。
- 顶级任务区和每个父任务末尾各自提供默认折叠的“已作废 N”分组，采用棕橙色、归档图标和双删除线，与已完成分组及计数完全隔离；详情卡可填写原因作废或重新启用。
- 重复任务完成或作废都继续产生下一截止实例；`recurrenceSourceId/seriesKey/instanceKey` 防止同一下一实例重复创建。
- preload/IPC 暴露通用 plain DTO 接口：查找稳定实例键、并发串行的幂等补实例、作废跨日本地日期且不可顺延的 active 实例。这里不包含每日简报、晨练或学习业务判断。
- `ensureInstance` 直接一次原子写入完整实例，不再执行 create 后 save。故障注入验证 rename 前失败后没有 Markdown 或 `.tmp` 半实例残留，随后重试只产生一个 revision=1 实例。完成和作废统一复用现有 next，覆盖 `void → restore → complete` 后仍只有原下一实例。

## Headless 自动化入口（2026-08-09）

- 新增编译产物 `dist-cli/cli/taskAutomation.js`，自动化通过 stdin/stdout 的 `bearai.todo/automation@1` plain JSON 协议调用相同 `TaskRepository`，必须显式传入已有工作区绝对路径。CLI 不初始化任意目录，也不接受外部直接拼 frontmatter。
- `capabilities/find-instance/ensure-instance/void-expired` 覆盖能力探测、幂等查询和创建、跨日作废与写后仓储读回。回执包含状态、实例日期、稳定 key、revision 和原因；逐任务失败不吞掉已成功回执。
- `TaskRepository` 的创建、保存、完成、作废、恢复、幂等实例、过期维护和任务位置变更统一进入可重入的 `.bearai-write.lock`。这使正在运行的 Electron 与 CLI、以及两个 CLI 进程之间串行写入；原有 revision 冲突继续阻止锁等待期间的人工修改被旧请求覆盖。
- 自动测试真实启动 Node 子进程，覆盖双 CLI 并发同 key、应用模拟持锁等待、锁超时无半实例、异常进程残留锁恢复、重复运行零重复、部分 revision 冲突、旧 task@2 保留和 JSON-only stdout。每日简报的业务规则与 automation.toml 不在本项目批次修改，仍由入口会话验收后启用。

## 项目跨父拖拽、主题归档对话框与富文本修复（2026-08-09）

- 项目落点领域服务统一解析 `before / inside / after`：前后只允许同父排序，中央允许子项目整体移动到合法目标下；仓储在工作区写锁内重新校验 revision、循环关系和路径边界。隔离 Electron 验证跨父移动后子树、两层任务、计数及磁盘读回保持一致，并实际验证自身和后代落点为禁止状态。
- 归档警告不再调用系统默认确认框，改用主题变量驱动的应用内 `alertdialog`。对象名称、未完成任务数量和影响范围明确展示；取消、确认、右上角关闭、Esc、点击遮罩、焦点锁定及触发点焦点恢复均进入真实 Electron smoke。
- Milkdown/Crepe 实例由 Vue `ref` 改为 `shallowRef`，避免深响应式 Proxy 破坏编辑器私有字段并抛出 `Cannot read from private field`。固定工具栏改用 ProseMirror 官方命令，真实 Electron 键盘选区和鼠标按键已覆盖标题、粗体、斜体、删除线、两类列表、引用、行内代码、代码块、撤销/重做、格式取消与跨段落格式化；Markdown 自动保存后由仓储回读。
- 强制中止 smoke 时曾因残留 Electron 向已关闭 stdout 写入而出现 `EPIPE` 系统错误；验收命令现将输出定向到隔离日志，暂停时清理项目自身的残留 Electron 进程，不影响正式数据。
- 固定工具栏新增明确可见的图片上传入口；选区浮动工具栏的粗体、斜体、删除线、行内代码和链接均以真实选区逐项验证应用与取消。系统剪贴板的纯文本、HTML 格式/链接和图片均经过 Electron 原生剪贴板路径；图片与按钮上传共生成两份受管 inline 附件及 Markdown 相对引用。关闭进程后重启同一隔离工作区，仓储、附件预览和编辑器图片均成功读回。
- 删除没有生产消费者、只能自证常量的 `editorCommands` 模块与测试；工具栏能力以生产组件的命令绑定和真实 Electron 行为为唯一清单。
- 任务列表头部使用列表容器查询而非整窗媒体查询。容器宽度不超过 900px 时，项目标题/面包屑位于第一行，查询、三组统计和更多按钮位于第二行；标题禁止逐字断行并使用省略，更多按钮保持至少 40px 可点击宽度。2048×921 的高级详情挤压态实测列表宽 762px并进入两行；1440×900、1280×800 采用详情覆盖退化，列表无横向溢出。
- 所有新建/重命名项目对话框以 Vue ref 和 `nextTick` 聚焦名称输入框；已有名称会全选。触发元素显式传入打开函数，Esc、取消和关闭后恢复触发点焦点；名称输入框直接处理 Enter 提交。隔离 Electron 验证 `document.activeElement`、Esc 关闭/恢复及 Enter 创建。
