# 实施进度与恢复断点

## 2026-08-09：Windows 图标与安装包

- 新增原创熊头与任务勾选组合图标，并生成包含 16、24、32、48、64、128、256 像素层级的 Windows ICO。
- 使用 electron-builder 生成 x64 NSIS 安装包；安装过程允许选择目录，并始终创建桌面快捷方式及开始菜单快捷方式。
- 卸载边界明确为只移除程序和快捷方式，`deleteAppDataOnUninstall=false`，不会删除本机设置、工作区注册表、任务 Markdown 或附件。

## 2026-08-08：项目与任务拖拽排序、重挂和跨项目移动

- 项目支持顶级同级及同父子项目排序；非法跨父拖拽不触发 IPC。子项目“移动到”过滤当前父级、自身、后代和归档目标，并采用确认、revision 校验、目录整体 rename 与配置失败回滚。
- 任务支持同层前/后排序、成为子任务、换父、回根，以及拖到左侧项目后确认整体跨项目移动。领域层拒绝自身/后代循环、来源变化、目标层级错误和 revision 冲突。
- renderer/preload 只传 plain placement DTO，主进程再次校验并调用 Markdown/目录仓储事务。搜索或过滤状态不允许排序。
- 自动测试覆盖领域行为；Electron smoke 通过完整 dragstart/dragover/drop 事件链并回读 Markdown。Windows 原生 SendInput 会进入 Chromium 阻塞 drag loop，未作为稳定 CI 方案；真实人工鼠标验收仍需单列。
- 拖拽状态提供前后插入线、成为子任务高亮、合法项目高亮和禁止状态。键盘式任务移动菜单尚未实现，保留为后续可访问性工作。

## 2026-08-08：主题、今日待办与日期选择批次

- 内置七套主题采用完整且互异的 token 组，覆盖场景层、面板、卡片、悬浮、双强调、文字、边框、危险色和阴影；墨石为明确深色主题。

- 自定义主题改为稳定 ID 的多主题集合，支持新增、编辑、复制、应用、删除与明确回退；背景复制到受管目录并通过安全协议解析。
- “今日待办”改为本地日历日截止窗口查询，默认 3 天、范围 0–30；任务卡显示窗口外、临近、今天、超时四态标签。
- 修复日期选择器随快捷菜单卸载的问题；提醒使用日期时间，截止使用仅日期，均 Teleport 到顶层并进入统一任务自动保存。

本批不改变项目整体 `in-progress` 状态；Windows 安装包、完整人工回归以及更深入的可访问性审计仍待后续完成。

## 2026-08-07 主布局回归修复

真实主界面复现发现 CSS Grid 将侧边栏宽度 `278px` 误写进了行定义，导致侧边栏只有约 278px 高、账号入口悬在页面中部并产生整窗滚动。现改为固定 42px 标题栏与 `minmax(0, 1fr)` 内容行；未选任务时详情轨道为 0，选中任务时才扩展为 340px。Electron 冒烟新增运行时尺寸门禁：1280×800 窗口中侧边栏高度必须超过 700px且不越界、主列表宽度超过 900px、body 不得产生额外滚动。

## 2026-08-07 图标、字体与点击热区

## 2026-08-07 任务详情与附件批次

任务详情中的提醒、截止时间和重复由禁用占位改为真实控件并写入任务 Markdown；主进程在启动和任务保存后调度 Windows 本地通知。备注上方新增简单/高级任务单选按钮组，高级模式以 280ms 边界动画将详情栏从 340px 扩展到约 680px，并使用 Markdown 工具栏、源码与安全转义后的同屏预览。窄屏退化为右侧覆盖面板；高级面板打开时中间栏标题和查询分行、隐藏统计，避免横向溢出。

附件选择后复制进工作目录，frontmatter 只记录元数据和相对路径。附件卡片显示扩展名徽标、文件名、大小和 MIME；点击打开应用内预览弹窗，支持图片、音视频、PDF 和文本类文件，不支持格式显示说明。所有弹窗均提供另存为按钮，移除时删除受路径边界保护的附件实体并更新 Markdown。

## 2026-08-06 运行时缺陷修复

根因是 sandbox preload 使用 ESM 编译产物，bridge 未注入后渲染层又静默使用内存 mock，造成任务看似成功但重启丢失，分组则无反馈。现改为 sandbox 可执行的 CommonJS preload，增加健康检查并移除全部任务内存回退；bridge 失败会显示错误。Vite 生产资源改为相对路径，`npm start` 加载构建版，只有 `--dev` 才访问开发服务器。真实 Electron 冒烟已验证分组和任务可重新读取且对应 Markdown 文件存在。

## 2026-08-07 自动保存、Milkdown 与展开模型修正

preload 对 task、嵌套 attachment、project patch 与 settings patch 统一转换为 JSON 兼容纯 DTO，渲染调用附件操作前再次去除 Vue Proxy，修复 `An object could not be cloned`。任务文本采用 550ms 防抖、单队列串行保存；关闭详情、切换任务/项目和应用关闭按钮会 flush。界面显示未保存、正在保存、已保存、保存失败；失败不再调用 `load()` 覆盖草稿，revision 冲突同时保留本地和磁盘版本供选择。

高级详情宽度固定为窗口的 50%，窄窗口仍采用右侧覆盖层，列表区不产生横向滚动。高级编辑器为 Milkdown/Crepe，正文仍只写 Markdown；固定工具栏暴露标题、粗体、斜体、删除线、列表、引用、代码与撤销/重做，图片进入受管附件并通过安全协议显示。截止时间和提醒使用 Vue Datepicker，并在外层提供今天、明天、下周等快捷选择；保存格式仍为 ISO 8601。项目菜单分成独立“任务展开”和“项目展开”。任务展开又分为互斥默认策略 `defaultTaskExpansion.mode`（默认不展开或按固定层级展开）与独立记忆开关 `rememberTaskExpansion`；项目字段 `showSubprojects` 双向不联动。固定深度只有第一至第五层和全部。旧三态及前一错误迭代字段只在读取时迁移，不再写回。
