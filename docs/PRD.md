# 熊智ToDo 产品需求（MVP）

## 目标

提供接近 Microsoft To Do 核心操作习惯的本地桌面待办体验，同时保证 Markdown 可读、可迁移、可外部编辑，未来可安全同步。

## MVP

- 智能列表：我的一天、重要、计划内、全部、已完成、任务。
- 自定义列表及列表组；安全改名、排序、归档，删除必须可恢复或明确确认。
- 快速添加、完成/恢复、重要、排序、搜索。
- 步骤、我的一天、提醒、截止日期、重复、标签、备注、附件及时间信息。
- 本地提醒；清晰的重复实例生成语义；我的一天按本地日期自然重置。
- Windows 桌面三栏布局，窄窗口可收起详情。

## 非目标

首期不做微软账号、Exchange、Outlook、Planner、真实共享/分配、云同步、移动端、跨设备协作。不存在的能力不展示伪按钮。

## 验收门禁

数据往返保真、未知字段保留、原子写入、外部改动冲突、损坏恢复与迁移必须自动测试；构建和类型检查通过；窗口交互与系统通知最终需 Windows 人工验收。
